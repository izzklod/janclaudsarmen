Two production systems. Built in Claude Code.

Each one takes a brief and returns finished, editable ads. A person approves the copy and reviews the result. The prompts and scripts stay private; this is how they run.

Static ads system

Reference ads in, a full set of editable statics out, up to 50 in one Canva link.

  1. Brief

    The day’s reference ads and performance notes go in. Each reference sets one variation’s layout and style.

    Claude Code
  2. Copy

    Headline, subline, proof and call to action for every ad. Each claim comes from an approved, sourced list.

    You approve
  3. Generate

    Prompts follow the reference style with the approved copy built in. Two tries per ad, the cleanest one kept.

    Higgsfield
  4. Make it editable

    The image is uploaded and split into layers, so text and products can still be moved by hand.

    Canva Magic Layers
  5. Check and fix

    Spelling, fonts, alignment, AI artefacts and claims are checked and corrected on each design.

    QC pass
  6. Deliver

    Resized to 4:5 and 1:1, merged into one design, exported, with a short report of what needs a decision.

    Canva

Video ad system

Raw clips and a script in, every hook cut, voiced, scored and laid out in CapCut.

  1. Job file

    The brief’s hooks and body lines go in word for word. One job per ad, so ads never collide.

    Claude Code
  2. Transcribe and match

    Every raw clip is transcribed and matched to its script line. A missing line is flagged before editing starts.

    Transcription
  3. Tight cut

    One cut per hook with no dead air, then verified: every script word present, no leftover pauses.

    Auto edit
  4. Voice and music

    One consistent voice across all hooks, and a different music track for each hook.

    Credits approved
  5. Compose

    B-roll, motion graphics, captions and the CTA, timed to the script. Something changes on screen every two seconds.

    HyperFrames
  6. Review

    Automatic checks for frozen frames, flashes and loudness, then a frame-by-frame look before anything ships.

    You review
  7. CapCut handoff

    Layers export as an import kit and the timeline is built in CapCut for the final hand edit.

    CapCut
